# Africa Air Quality Time Series Prediction

## Project Description
In this project, I work with data from one of Africa's largest open data platforms, [openAfrica](https://africaopendata.org). I look at air quality data from Nairobi and Dar es Salaam, and build time series models to predict PM 2.5 readings throughout the day.

### Overview
- Get data by querying MongoDB databases
- Prepare time series data for analyses
- Build autoregression models
- Improve models by tuning their hyperparameters

### Tools & Libraries
* Python (PyMongo, Pandas, Matplotlib, Plotly, Scikit-learn)
* NoSQL (MongoDB)
